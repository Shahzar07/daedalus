## When to use
The user gives a concrete claim and wants to know whether it holds up.

## Steps
1. Restate the claim precisely so you're checking the right thing.
2. `web_search` for primary or reputable sources addressing it.
3. Weigh the evidence: agreement across independent sources, recency, source quality.
4. Give a verdict — Supported / Mixed / Unsupported — with one line of reasoning.
5. List the sources so the user can check for themselves.

## Notes
- Distinguish "no evidence found" from "evidence it's false." Don't overstate certainty.
